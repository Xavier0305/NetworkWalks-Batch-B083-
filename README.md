# NetworkWalks-Batch-B083-

Cybersecurity & Reconnaissance Lab
Overview

This repository contains my practical cybersecurity work completed as part of the Networkwalks Cybersecurity Internship.

The purpose of this project is to document hands-on reconnaissance, information gathering, network discovery, and basic security assessment activities performed in a controlled lab environment.

Objectives
Perform passive and active reconnaissance.
Identify live hosts within a designated IP subnet.
Gather information about target domains and web technologies.
Identify open ports and running services.
Perform basic web technology fingerprinting.
Detect and analyze Web Application Firewall (WAF) presence.
Document findings with screenshots and command outputs.
Maintain organized evidence of practical cybersecurity activities.
Tools Used
Nmap – Network discovery and port/service scanning
WhatWeb – Web technology fingerprinting
WAFW00F – WAF detection and fingerprinting
Kali Linux – Cybersecurity testing environment
UTM – Virtualization environment
GitHub – Documentation and version control

Reconnaissance Activities
1. Network Discovery

Nmap was used to identify live hosts within the assigned network subnet and gather information about accessible systems.

2. Web Technology Enumeration

WhatWeb was used against the target domain to identify technologies, web servers, headers, cookies, and other publicly observable web technologies.

3. WAF Detection

WAFW00F was used to determine whether a Web Application Firewall could be identified in front of the target website.

4. Documentation

The results of the reconnaissance activities were documented through command outputs and screenshots and compiled into the project report.

Evidence

Screenshots and supporting evidence are included in the Screenshots directory. The detailed findings and explanations are available in the reconnaissance report located in the Reports directory.
